# 🏠 Rent & Expense Calculator

A beginner-friendly Python command-line tool that calculates shared household costs per person.

## 🧰 Built With
- Python 3

## ▶️ Run the Calculator

Install Python 3, then run:

```bash
python main.py
```

## 🧮 How It Works
Enter:
- Monthly rent
- Food expenses
- Electricity units or reading
- Cost per electricity unit
- Number of people sharing the expenses

The program calculates the electricity cost, total expenses, and each person's share.

**Formula:**

`Electricity cost = electricity × charge per unit`

`Per-person share = (rent + food + electricity cost) ÷ people`
